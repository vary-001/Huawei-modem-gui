## 🚀 HOW TO USE

### Quick Start (2 Steps)

#### Step 1: Start Services
```bash
# Terminal 1 - Backend
cd modem-backend && npm run dev

# Terminal 2 - Frontend
cd modem-ui && npm run dev
```

#### Step 2: Open Browser
```
http://localhost:5174
```

### Make Your First Call
1. Enter: `100`
2. Click: `Place Call`
3. Allow: `Microphone` (browser permission)
4. Control: Use media controls
5. End: Click `End Call`

**Done!** ✅
