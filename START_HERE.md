## 🚀 GETTING STARTED (2 MINUTES)

### Step 1: Start Backend
```bash
cd modem-backend
npm run dev
```

### Step 2: Start Frontend
```bash
cd modem-ui
npm run dev
```

### Step 3: Open Browser
```
http://localhost:5174
```

### Step 4: Make Your First Call
1. Enter: `100`
2. Click: `Place Call`
3. Allow microphone when prompted
4. Click: `End Call` to disconnect

**Total Time**: 2 minutes ⏱️
